# ArchSystem

The Achaea system for Mudlet in one file: `Achaea.xml`.

## Install (once)

1. Download `Achaea.xml` and keep it somewhere permanent (e.g. your Mudlet profile folder).
2. Mudlet: Toolbox > Module Manager > Install, pick `Achaea.xml`. Leave **Sync** unticked.
3. In game: `acs update url https://raw.githubusercontent.com/testostapwn/ArchSystem/master/Achaea.xml`

## Update

Type `acs update`. It downloads the latest `Achaea.xml` from this repository,
checks it, replaces the module file and reloads. Your settings are kept
(they're in their own files in the profile folder). `acs update local` just
reloads the file you have.

Help in game: `shelp`.
